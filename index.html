Sincronización en la nube ☁

Conserva tus exámenes, días libres y notas en el ordenador y en el móvil.

☁
Datos guardados en este navegadorTus exámenes actuales no se borrarán. Para compartirlos entre dispositivos, conecta la nube.
Tu agenda actual está a salvo. La sincronización añade los datos que falten entre dispositivos; no sustituye toda tu agenda. Antes de conectarla por primera vez se guarda una copia local de seguridad.
Configuración necesaria una sola vez por sesión: GitHub Pages no tiene una base de datos propia. Esta opción utiliza tu repositorio de GitHub para guardar solo datos cifrados. Tendrás que conectar tu GitHub en cada dispositivo. La contraseña de cifrado debe ser la misma en ambos.

1. Autorizar tu propio GitHub

  1. Abre Crear token de GitHub (fine-grained).
  2. Selecciona Repository access → Only select repositories → agenda y en permisos Contents → Read and write. No concedas otros permisos.
  3. Copia el token y pégalo aquí, no en el chat. Guárdalo en tu gestor de contraseñas para conectarte desde el móvil.

2. Conectar y sincronizar

Privacidad: las notas y exámenes se cifran antes de enviarlos a GitHub, pero el archivo cifrado estará en un repositorio público. Usa una contraseña larga y única. Tu token y contraseña solo se conservan en la sesión de esta pestaña; no se suben a GitHub. Si cierras la sesión tendrás que introducirlos otra vez para sincronizar. Aunque la nube falle, seguirás pudiendo usar tus datos locales.
